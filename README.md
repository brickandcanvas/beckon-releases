# Beckon for Mac

AI in your notch that does the work. Ask out loud, and Beckon researches, compares and acts across your Mac.

This repository only hosts Beckon's downloads and updates. Beckon's source code isn't public.

## Download

**[Download the latest Beckon for Mac](https://github.com/brickandcanvas/beckon-releases/releases/latest/download/Beckon.dmg)**

Or visit [beckonapp.ai](https://beckonapp.ai).

## Requirements

- macOS 14 Sonoma or later
- A Mac with Apple silicon (M1 or later)

## Install

1. Open `Beckon.dmg`.
2. Drag **Beckon** into **Applications**.
3. Open Beckon and sign in with Apple or Google.

Every release is signed and notarized by Apple.

## Updates

Beckon checks for updates once a day and asks before installing. You can also choose **Check for Updates…** from the menu bar icon, or in **Settings → About**.
